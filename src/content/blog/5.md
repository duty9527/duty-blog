## 1.安装rvm ##

    sudo apt-add-repository -y ppa:rael-gc/rvm

错误：“add-apt-repository command not found” Error
解决办法：`sudo apt install software-properties-common`
安装完成后再次添加源

    sudo apt-add-repository -y ppa:rael-gc/rvm
    sudo apt update -y
    sudo apt -y install rvm


<!-- more -->


错误：Command 'rvm' not found, but there are 19 similar ones.
解决办法：  `source /etc/profile.d/rvm.sh`
查看可用ruby版本`rvm list known`，有输出则安装成功。
## 2.安装ruby ##

    rvm install ruby-2.7
    ruby -v 输出版本号则安装成功

## 3.安装bundler ##

    gem install bundler
    bundle -v   # 输出版本号则安装成功
