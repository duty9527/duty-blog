### 一、如何在manjaro上使用手机投屏
1. 安装scrcpy
```shell
sudo pacman -S scrcpy
```
2. 安装adb
```shell
sudo pacman -S adb
```


<!-- more -->


3. 打开手机的开发者选项
4. 选择连接方式
    - usb连接
    手机连接电脑，选择传输文件模式，打开电脑终端，输入`adb devices`即可查看当前连接的设备，输入`scrcpy`，即可快速建立一个连接，不出意外的话，电脑上显示一个手机屏幕。
    - 无线连接
    1. 第一步和有线一样，连接电脑
    2. 连接成功后在终端输入`adb tcpip 5555`，端口可根据自己选择随意切换
    3. 查看手机的ip地址
    4. 终端输入`adb connect TELPHONE_IP:5555`，终端显示`connected to 192.168.100.19:5555`即连接成功
    5. 在终端输入`scrcpy`即可愉快的使用手机投屏

5. 一些参数及快捷键，你可以使用`-f`参数设置展示全屏，你可以通过`--turn-screen-off --stay`使其可以在手机息屏下使用，当然，`-h`永远是你的杀手锏，它不仅包含所有可用的参数，还包含投屏时的键盘快捷键

7. 一些快捷键

|作用|快捷键|
|---|----|
|返回|mod+B|
|主界面|mod+H|
|多任务|mod+S|
|关闭手机屏幕，电脑正常|mod+O|
|开启手机屏幕|右键单击|
|展开通知栏|mod+N|
|折叠通知栏|mod+Shift+N|
|全屏|mod+F|
> 注: `mod`为Linux下的视窗建，即`win`键
