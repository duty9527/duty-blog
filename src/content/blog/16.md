# Manjaro日常使用时的问题修复记录

### 1. 使用xface界面的情况下没有合适的音量调节方式
```
sudo pacman -S pulseaudio   #安装pulseaudio音量管理工具，并将其设置为状态栏的程序启动器
sudo pacman -S pavucontrol  #如果还有问题加上这个软件
```
> 补充：pavucontrol在界面上我更青睐

### 2. 关闭manjaro的警报音
```
xset b off
```
可以将其添加到开机自启中,以保证每次都生效。

### 4. 安装一个好看的主题以及图标
```
pacman -S gtk-engine-murrine gtk-engines  
sudo pacman -S numix-circle-icon-theme
```
主题建议去[源代码git仓库](https://github.com/vinceliuice/Mojave-gtk-theme)直接拉取，然后进入主题目录`./install`即可。然后去设置->外观中更改相应的主题。

### 13. 更换掉你老掉牙的fcitx4吧
- 卸载旧版本的fcitx4

```
sudo pacman -Rs $(pacman -Qsq fcitx)
```
- 安装fcitx5

```
sudo pacman -S fcitx5 
sudo pacman -S fcitx5-configtool  
sudo pacman -S fcitx5-qt
sudo pacman -S fcitx5-gtk
sudo pacman -S fcitx5-chinese-addons
sudo pacman -S fcitx5-material-color
sudo pacman -S kcm-fcitx5
sudo pacman -S fcitx5-lua
```
- 配置environment

```
sudo chmod 777 /etc/environment
vim  /etc/environment
```
写入如下内容
```
GTK_IM_MODULE DEFAULT=fcitx
QT_IM_MODULE  DEFAULT=fcitx
XMODIFIERS    DEFAULT=@im=fcitx
INPUT_METHOD  DEFAULT=fcitx
SDL_IM_MODULE DEFAULT=fcitx
```
- 你可能会遇到无法切换中英文的问题，可以尝试这样做

在~/.xprofile中添加以下内容，如果不出意外的话过一会就可以切换，如果不可以尝试先打开fcitx配置，随手配置一下，如果还不可以，尝试重启。
> 如果不存在这个文件直接创建一个
```
export XMODIFIERS=@im=fcitx
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
```
- 安装wiki词库
[fcitx5-pinyin-zhwiki](https://github.com/felixonmars/fcitx5-pinyin-zhwiki)
```
sudo pacman -S fcitx5-pinyin-zhwiki
```
